RapidSwing

A rapid application development framework for Java Swing, targeting Java 8 and newer: data binding, validated forms, data grids, CRUD screens, sign-in, translations, charts, wizards and an application generator.

Try the demo in your browser (experimental) Download Source code

What is in the box

rapidswing-core

Application lifecycle, services, event bus, background tasks with progress, navigation tree, quick open (Ctrl+K), F1 help, sign-in and roles, AES-256 encryption, translations, queries and charts.

rapidswing-binding & forms

Two-way binding and a fluent form builder with validation, warnings, wizards and user settings.

rapidswing-table & crud

Typed data grids with row actions, styles, compare and print; CRUD screens with server-side search and paging, detail tables, and screens generated from any JavaBean.

rapidswing-logviewer

Several log files merged in time order, format detection, regex search and follow mode.

rapidswing-rest

Screens for Spring Boot REST APIs from their OpenAPI document, at run time or as generated source.

rapidswing-generator

A wizard and command line that create SDI, MDI, dialog-based and Outlook-style applications.

Download and run

Both applications need Java 8 or newer. Download them from the latest release, then:

java -jar rapidswing-demo-0.1.0-SNAPSHOT-app.jar --app.theme=dark
java -jar rapidswing-generator-0.1.0-SNAPSHOT-app.jar

Or build from source with build (Windows) or ./build.sh (Linux, macOS), and start them with run demo and run generator.
