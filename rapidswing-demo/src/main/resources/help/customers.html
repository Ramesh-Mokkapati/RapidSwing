Customers

Finding customers

Fill in any search fields and press Search or Enter. Each field has an operator, such as contains, between or is empty. Recent searches can be run again from the Recent list. Use the paging bar under the list to move through the pages.

Working with several customers

Select rows with Ctrl or Shift, then use the buttons above the list or right-click: Deactivate works on active customers only, Compare shows two or more customers side by side with the differences marked, and Print prints the list.

Colors

Large balances are shown in green and bold; inactive customers are greyed out; overdue orders are red.

Keys

Ctrl+N new customer, Ctrl+S save, F5 refresh.
